# 公開ファイルに混ざってはいけない「環境ごとの語」の一覧。
#
# 使い方:
#   cp dev/secrets.local.example.txt dev/secrets.local.txt
#   実際の値を書き足す（このファイル自身には書かない）
#
# secrets.local.txt は .gitignore 済み。dev/egress_check.py がこれを読んで、
# README や docker-compose.yml などの公開ファイルを走査する。
#
# 1行1語。# で始まる行とからっぽの行は無視される。
# 書くもの:
#   - Dockerホストや他マシンのホスト名
#   - 契約しているISP・回線の名前
#   - グローバルIP、LANのIP（RFC予約のIPは書かなくていい）
#   - 実際に監視しているアカウント名
#   - 自分のドメイン
#
# 例（実在しない値です。消して実際の値を書いてください）:
my-docker-host
example-isp
198.18.0.1
some_watched_account
mydomain.example
